# qwerty-learner → Vue 3 重构规划 · 第四部分（v2）：特效组件规划 —— 库组件优先版

> **v2 修订说明**：按新原则全面改写——"别人验证过的交互效果 > 自己造的交互效果"。
> 凡是 vue-bits / Inspira UI 里有现成组件的交互点，一律直接采用库组件；此前 v1 中"自写路由过渡 / 自研 Toast / 不加特效"等方案全部废弃。
> v2 覆盖 v1 中冲突的部分；第三份文档（03-交互优化与验收）的九态矩阵与验收标准不受影响，继续有效。

---

## 一、交互设计的三个来源（本项目的分工）

| 来源 | 性质 | 包含内容 | 处理方式 |
|---|---|---|---|
| **① qwerty-learner 原项目** | 经大量真实用户验证的核心 UX | 字母三态变色、shake 抖动、300ms 吞键、confetti 双侧发射、错 4 次出 Skip、Tab 按住显示答案、自动发音、快捷键语义、弹窗结构 | **原样保留**（03 文档 25 条红线）——这不是自造设计，是别人的验证成果 |
| **② vue-bits / Inspira UI** | 经社区验证的成熟特效组件 | 入场动画、背景、文字特效、卡片光效、微交互、搜索框、按钮 | **直接拷组件源码进项目用**，不做自己的动画 |
| **③ 我自造** | —— | **应为零** | v1 中的自造项全部替换：自写 Toast → `sonner-vue`；自写路由过渡 → Vue 官方 `<Transition>` 标准方案；其余一律落回 ①② |

> 例外说明：Word/Letter 的打字判定组件（变色/shake/吞键）在两库里没有对应物，且属于来源①——**不引入任何库特效替换它**。

## 二、两库全景与接入方式

### 2.1 组件总量

| 库 | 总量 | 分类 | 安装 |
|---|---|---|---|
| Vue Bits | 5 类 209 项 | TextAnimations(33) / Animations(40) / Backgrounds(58) / Components(44) / Micro(34) | `npx jsrepo add https://vue-bits.dev`（交互选择，按组件声明自动装依赖） |
| Inspira UI | 12 类 155 项 | Backgrounds(27)/Button(5)/Card(10)/Cursor(5)/Device Mockup(2)/Forms&Input(6)/HTML in Canvas(7)/Miscellaneous(29)/Special Effects(14)/Testimonials(3)/Text Animation(32)/Visualization(15) | `npx inspira-ui@latest add <component>` |

两库都是 **shadcn 式源码拷贝**：组件 .vue 源码直接进项目，可改可删，无 npm 锁定。

### 2.2 依赖引擎归类（决定引入顺序）

| 引擎 | 体积(gzip) | 使用库 | 策略 |
|---|---|---|---|
| 纯 CSS / Tailwind | 0 | 两库均有 | 优先级最高 |
| motion-v | ~20KB | Inspira 全线 / vue-bits Micro | **第一个装**（物理微交互 + Inspira 文字类都靠它） |
| gsap | ~70KB | vue-bits 文字/动画类 | 第二个装（CountUp/AnimatedContent/BlurText/SpotlightCard 等） |
| ogl | ~45KB | vue-bits Backgrounds | 仅 Mobile 页异步 chunk + 可选氛围背景 |
| three.js / TresJS / Spline | >600KB | 两库 3D 类 | **排除**（HTML in Canvas / Shader 系列 / Globe 全不用） |

**主包预算**：gsap + motion-v ≈ 90KB gzip；`/mobile` 路由异步 chunk 可含 ogl。

## 五、操作流程：库组件怎么进项目、怎么验

### 5.1 安装步骤（工单 0 一次性做完）

```bash
# 1. 项目内初始化 jsrepo（vue-bits）
npx jsrepo init https://vue-bits.dev
npx jsrepo add https://vue-bits.dev          # 交互式勾选本表列出的组件

# 2. Inspira UI
npx inspira-ui@latest add aurora-background placeholders-and-vanish-input \
  file-upload animated-modal border-beam multi-step-loader

# 3. sonner-vue（toast）
pnpm add sonner-vue
```

- 组件落盘：`src/components/effects/`（vue-bits，改名 Fx 前缀）、`src/components/inspira/`（保留原名）、`src/components/common/`（FxGate/FxAppear 包装）。
- 每装一个，依赖按组件声明自动写入 package.json；装完立刻在 `/fx-lab` 目检。

### 5.2 特效试验场 `/fx-lab`（dev-only 路由，关键操作规范）

**所有库组件接入业务页面前，必须先在试验场逐个目检**：

1. 一个路由网格铺开本项目实际会用到的每个库组件实例（真实参数、深浅色双套）。
2. 每个组件记录：深浅色表现 / 参数调节结果 / 性能（DevTools Performance 录制 5s）/ reduced-motion 降级 / 移动宽度表现。
3. 目检不合格（过曝、抢焦点、掉帧）→ 调参或换同类备选 → 再检 → 通过才进业务工单。

### 5.3 守卫与红线（精简保留，仅 4 条）

1. **输入区零特效**：WordPanel/Word/Letter 不叠加动画；背景层 `-z-10` + `pointer-events:none`。
2. **输入路径不被阻塞**：keydown → 判定 → 渲染路径上无动画调用。
3. **WebGL 只在 Mobile 页**：主应用氛围背景用 Inspira CSS 系；ogl 只出现在异步 chunk；three.js 全库禁用。
4. **`FxGate` 守卫**：`fxConfig.ambient`（默认开）× `prefers-reduced-motion` × `navigator.hardwareConcurrency` 三重判定，不满足渲染静态降级；L2 组件全部经此包装。

设置项（config store 新增 key `fxConfig`）：`{ ambient: true, cursorFx: false }`，放「显示设置」Tab。
