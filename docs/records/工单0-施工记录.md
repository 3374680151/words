## 二、自测发现并修复的缺陷（细节）

| # | 缺陷 | 根因 | 修复 | 复测 |
|---|---|---|---|---|
| 1 | 页面 CSS 报错 `ui-active:` 变体不存在 | 平移时漏装 `@headlessui/tailwindcss` 插件（ui-active/ui-selected 变体的来源） | 补装并加入 plugins | ✅ 页面正常渲染 |
| 2 | `sonner-vue` 包已被下架（2023 unpublish），安装失败 | 依赖选型过时 | 改用 `vue-sonner`（shadcn-vue 现行方案，工单 1 集成） | ✅ 安装成功 |
| 3 | pnpm 12 拦截 esbuild/vue-demi 构建脚本 | pnpm 12 新策略（package.json 的 pnpm 字段已废弃） | `pnpm-workspace.yaml` + `--allow-build` | ✅ esbuild OK |
| 4 | **FxGate 永远走降级分支** | Vue 对 Boolean 类型 prop 有"缺省强转 false"行为，`props.when ?? true` 不生效（when 缺省时是 false 不是 undefined） | `withDefaults(props, { when: true })`（显式 default 覆盖强转） | ✅ 放行正确，开关切换生效 |
| 5 | **FxCountUp 停在 0** | `gsap.fromTo()` 误传 4 个参数，onUpdate 所在对象被忽略 | 改为标准 3 参调用，onUpdate 并入 toVars，闭包代理读值 | ✅ 动画完成（progress 1 → 目标值） |
| 6 | FxShinyText 亮色底对比度过低（原库针对深底设计） | 基础色 #b5b5b5a4 在白卡上不可读 | 亮色 #9ca3af / 深色 #ffffff66 双套 | ✅ 待截图复验 |
| 7 | fx-lab 横幅提示原因错误（实际是 ambient 被关，显示"硬件分级"） | 三态文案逻辑不完备 | 补全"氛围特效已关闭/reduced-motion/硬件分级"三态 | ✅ |
