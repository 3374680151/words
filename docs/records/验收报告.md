## 三、原项目缺陷修复清单（重构收益）

3. Dialog 打开时 Enter/Esc 冒泡误触页面返回 → activeDialogCount 守卫
4. 错题分组 O(n²) → Map
5. 防闪烁脚本读废弃 key → 新 key
6. alert() ×3 → sonner Toast（输入法提示/导出失败/导入失败）
7. 错题本空状态缺失 → EmptyState 引导
8. 词表加载失败无处理（死转圈）→ 错误卡片+重试
9. 统计页无 loading → 骨架
10. 结果页按钮可连点 → 200ms 防抖
11. IndexedDB 写失败静默丢失 → error Toast
12. 复习面板/统计页无 loading → 补齐
13. 删除无二次确认（错题本+错题表）→ AlertDialog
14. 词书页无搜索 → 🆕 防抖搜索
15. 设置 Tab 不记忆 → 🆕 会话记忆
16. Drawer 窄窗溢出 → min(35rem,92vw)
17. 删除后页码不回退 → 修正
18. ViewSetting 非受控滑杆 → 受控
19. ChapterRecord.inputAccuracy（见 1）
20. 死代码（旧 Gallery/死 Action×3/isLoopSingleWord/revision 表）不迁移
