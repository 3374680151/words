# qwerty-learner → Vue 3 重构规划 · 第五部分：逐页施工工单与自测闭环（操作手册）

> 回答三个问题：**怎么改**（一页一改，每页固定流水线）、**怎么操作**（库组件先试验场目检再接入；浏览器实测每一步交互）、**怎么验收**（每页一张检查单，全绿才进下一页）。

---

## 一、总原则：一页一改、改完即测

1. **页面级交付**：每次只做一个页面/一张工单，做完立刻可跑、可点、可对照，不攒大批未验证代码。
2. **库特效先行**：进入任何页面工单前，该页用到的库组件必须已在 `/fx-lab` 目检通过（见 04 文档 5.2）。
3. **自测闭环**：每页完成后，我自己起 dev 服务，用浏览器自动化（browser-use 技能）把该页检查单**逐项实际执行一遍**——不是"应该没问题"，而是亲手点过、输过、看过动画、看过失败态。
4. **双栏对照**：原项目（`F:\notebook\word\qwerty-learner`，`pnpm dev` 起 5173）与 Vue 版并排跑，逐项对照视觉与交互。
5. **缺陷登记**：每页一张施工记录表，缺陷 → 修复 → 复测，全绿才勾"完成"。

---

## 二、每页固定流水线（6 步）

```
① 建   实现本页组件（库特效已目检 + 原项目交互红线保留）
② 跑   pnpm dev → http://localhost:5174（原项目占 5173）
③ 点   browser-use 按本页【交互检查单】逐项执行：点击/输入/快捷键/空态/失败态/连点
④ 比   截图与原项目同页面并排比对（布局/颜色/字号/动画时机）
⑤ 修   发现缺陷 → 登记 → 修复 → 重新执行 ③④
⑥ 验   本页检查单全绿 + lint + vue-tsc 通过 → 勾完成 → 下一页
```

浏览器实测要点（每页都做）：
- 正常流 + 空态 + 失败态（DevTools 断网/拦请求）+ 连点 + 窗口缩放（1100/1440 断点）+ 深浅色各跑一遍。
- 每张截图落盘 `vue-refactor-plan/screenshots/工单N/`，命名 `步骤-状态-亮或暗.png`。
