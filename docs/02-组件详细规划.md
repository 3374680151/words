## 二、打字页组件（核心）

### 2.1 `pages/Typing/index.vue` ⭐（TypingPage）

- **来源**：`pages/Typing/index.tsx`
- **职责**：页面编排、词表加载、状态机驱动、全局监听。
- **内部状态**：`isLoading`（词表请求中）。
- **交互状态与触发**：
  1. **加载态**：`isLoading=true` → 居中 AppSpinner（不渲染 WordPanel）。
  2. **加载失败态（🆕）**：请求失败 → 显示错误卡片（错误信息 + "重试" AppButton，调 `reload()`）；不留白。
  3. **空数据态（🆕）**：本章 0 词 → 空状态卡片 + "回到词书选择" 按钮（原项目会一直转圈，修复）。
  4. **开始前/暂停**：`!isTyping && !isFinished` → WordPanel 上覆盖 `backdrop-blur-sm` 遮罩 + "按任意键{time? '继续':'开始'}"。
  5. **打字态**：`isTyping=true`。
  6. **完成态**：`isFinished` → 渲染 ResultScreen（+DonateCard），不渲染 WordPanel。
  7. **字典校验**：`watch(dictId)`：id 不在 `idDictionaryMap` → 重置 cet4 + chapter 0；`watchEffect` 守卫 `chapter >= chapterCount` → 归 0（修复 render 期副作用）。
  8. **window blur** → `store.pause()`；window keydown（仅 `!isTyping`）：合法字符键或空格、无 alt/ctrl/meta 且不是 Enter → preventDefault + `store.start()`。
  9. **计时器**：`watch(isTyping)` 启停秒级 interval。
  10. **保存章节**：`watch([isFinished, isSavingRecord])` → `saveChapterRecord`；**失败时 error Toast（🆕 P0-7）**。
- **结构**：`[ResultScreen?] <Layout><AppHeader>…按钮组</AppHeader> <WordPanel | spinner> <SpeedBar/> </Layout> <WordListDrawer/>`

### 2.3 `WordPanel.vue` ⭐

- **来源**：`pages/Typing/components/WordPanel/index.tsx`
- **职责**：单词区编排 + 上/下词预览 + 译文显隐 + 进度条 + 输入通道分发。
- **内部状态**：`wordComponentKey`（循环 remount）、`currentWordExerciseCount`（当前词循环次数）、`isShowTranslation`（Tab 按住）。
- **交互与触发**：
  1. `onFinish` 三分支（顺序固定）：
     - **循环未满**（`currentWordExerciseCount < loopWordTimes-1`）：计数+1 → `loopCurrentWord()` → `wordComponentKey++`（`:key` 强制重建 Word，清空输入）；
     - **进入下一词**：计数归 0 → `nextWord(updateReviewRecord=isReviewMode)`；
     - **章节完成**：`finishChapter()`；复习模式额外 `finishReview()`。
  2. 快捷键：`Ctrl+Shift+←/→` → `skipToIndex(clamp(index±1))`；Tab keydown/keyup → `isShowTranslation`。
  3. 预取：`prefetch(nextWord?.name)`（watch 当前 index）。
  4. 遮罩文案："按任意键{time?'继续':'开始'}"。
- **布局**：顶部 PrevAndNextWord（`config.isShowPrevAndNextWord && isTyping`）；中部 Word + Phonetic（`phonetic.isOpen`）+ Translation（`showTrans = isShowTranslation || isTransVisible`，`trans.join('；')`）；底部 ChapterProgress（`isTyping ? 'opacity-100' : 'opacity-0'`）。

### 2.5 `Word.vue` ⭐⭐（全项目最核心组件）

- **来源**：`pages/Typing/components/WordPanel/components/Word/index.tsx` + `Letter.tsx` + `index.module.css`
- **Props**：`{ word: WordWithIndex, onFinish: () => void }`
- **Expose**：`play()`（发音，供 Ctrl+J 与父组件调用）
- **内部状态** `wordState`（reactive，组件局部，不进 store）：

```ts
{ displayWord, inputWord, letterStates: LetterState[],   // 'normal'|'correct'|'wrong'
  isFinished, hasWrong, hasMadeInputWrong, wrongCount,
  startTime, endTime, correctCount, letterTimeArray: number[],
  letterMistake: Record<number, string[]>, randomLetterVisible: boolean[] }
```

- **watchers（6 个，全部平移）**：
  1. `watch(() => props.word)`：重建 wordState——空格→显式 `␣`、` …`→`..`、letterStates 全 normal、randomLetterVisible 生成（`Math.random()>0.4` 即 60% 可见）。
  2. `watch(inputWord)` **对错判定核心**：前置短路（hasWrong / 长度 0 / displayWord 空）；比较最后输入字符 vs `displayWord[len-1]`，`config.isIgnoreCase` 时双方 toLowerCase；
     - **对**：`letterTimeArray.push(Date.now())`、correctCount+1、letterStates[last]='correct'、`reportCorrect()`；若是最后一个字母 → isFinished=true + 播 correct 提示音，否则播按键音；
     - **错**：播 beep、letterStates[last]='wrong'、hasWrong=true、wrongCount+1、letterTimeArray=[]（计时清零）、letterMistake[len-1].push(inputChar)、`reportWrong(...)`；`chapter===0 && index===0 && wrongCount>=3` → TipAlert（插件冲突提示）。
  3. `watch(hasWrong)`：**300ms setTimeout 清空** inputWord=''、letterStates 重置 normal、hasWrong=false；期间所有 add 输入被吞（**手感红线，必须保留**）；onUnmounted 清理定时器。
  4. `watch(isFinished)`：`setSaving(true)` → `saveWordRecord(...)` → `onFinish()`；**写库失败 → error Toast + setSaving(false)（🆕 P0-7）**。
  5. `watch(wrongCount)`：`>=4` → `store.showSkip()`。
  6. `watch([isTyping, inputWord.length])`：输入长度 0 且打字中 → 自动发音。
- **快捷键**：Tab keydown/keyup → `isHoveringWord`（按住显示全词，配合 isShowAnswerOnHover）；`Ctrl+J` → `play()`。
- **字母显隐 `getLetterVisible(i)`**（听写模式核心，原样平移）：
  1. `letterStates[i]==='correct' || (isShowAnswerOnHover && isHoveringWord)` → 显示；
  2. `wordDictation.isOpen`：hideAll→false；hideVowel→元音(AEIOU)隐藏；hideConsonant→辅音隐藏；randomHide→randomLetterVisible[i]；
  3. 默认显示。不可见渲染 `_`。
- **渲染**：InputHandler + Notation（romaji/hapin，ruby 注音 `/(.+?)\((.+?)\)/g` + isKanji）+ 字母行（v-for Letter）+ WordPronunciationIcon（`-right-12`，开关控制）+ TipAlert。
- **动画**：`hasWrong` 时容器挂 `.wrong` → `shake 0.82s cubic-bezier(0.36,0.07,0.19,0.97)`（keyframes：10%/90% -1px → 20%/80% 2px → 30%/50%/70% -4px → 40%/60% 4px）。
- **`Letter.vue`**：props `{ letter, state='normal', visible=true }`；纯展示；颜色：普通字母 normal `text-gray-600 dark:text-gray-50` / correct `text-green-600 dark:text-green-400` / wrong `text-red-600 dark:text-red-400`；`␣` 组 normal `text-gray-400` / correct `text-green-400 dark:text-green-700` / wrong `text-red-400 dark:text-red-400`；字号 `config.fontSize.foreignFont`。

### 2.7 `ResultScreen.vue` ⭐（结果页）

- **来源**：`pages/Typing/components/ResultScreen/`（index、RemarkRing、ConclusionBar、WordChip）
- **挂载副作用**：`store.tick(0)` 补算最终 accuracy/wpm。
- **布局**：`fixed inset-0 z-30` 半透明灰底 + 白卡片 `rounded-3xl w-[90vw] max-w-6xl` + Vue `<Transition>` 淡入。
- **展示数据**：
  - 左列 3 个 `RemarkRing.vue`（props `{remark, caption, percentage?, size=7rem}`）：正确率（SVG arc clip-path，clamp 0-100，100 不画）/ 耗时 mm:ss / WPM；
  - 标题：`${dict.name} 第X章` / 复习模式 `错题复习`；
  - 中部错词墙：`wrongWords = userInputLogs.filter(wrongCount>0).map(words[log.index])` → `WordChip.vue`（props `{word}`；点击发音；hover @floating-ui 释义 tooltip；`.word-chip` 样式平移）；
  - 底部 `ConclusionBar.vue`：`correctRate = floor((len - wrongWords.length)/len*100)`；三档评语：`>=85` IconHeart "表现不错！只错了 X 个单词"/全对 "全对了！"；`>=70` IconHandThumbUp "有些小问题哦…"；否则 IconExclamationTriangle "错误太多，再来一次如何？"
- **confetti**：在 TypingPage 层 `useConfetti(isFinished)`：isFinished 后 **250ms** 左侧 `{particleCount:50, angle:60, spread:100, origin:{x:0}}`、**400ms** 右侧 `{angle:120, origin:{x:1}}`；默认 `colors:['#5D8C7B','#F2D091','#F2A679','#D9695F','#8C4646'], shapes:['square'], ticks:500`。
- **按钮区 `ResultActions.vue`**（🆕 P0-6：全部按钮加 200ms 防连点）：

| 按钮 | 快捷键 | 行为 |
|---|---|---|
