# qwerty-learner → Vue 3 重构规划 · 第一部分：技术选型与架构设计

> 蓝本：`F:\notebook\word\qwerty-learner`（React 18 + jotai 2 + Vite 4 + Tailwind 3 + Dexie 3 + shadcn/Radix + headlessui）
> 目标：完整复刻成熟产品的使用体验（不是外观相似的演示页），并在原项目缺陷处做交互补强。
> 本文档共三部分：**01 技术选型与架构** / **02 组件详细规划** / **03 交互优化与验收**。

---

## 1. 调研结论摘要（重构蓝本）

### 1.1 原项目架构一览

| 层 | 实现 |
|---|---|
| 全局配置 | jotai `atomWithStorage` / `atomForConfig`，共 **18 个 localStorage key**，读取时做"缺字段合并默认值"防御 |
| 打字状态机 | `useImmerReducer` + Context，`TypingState` + **19 个有效 Action**（枚举里另有 4 个死 Action） |
| 本地数据 | Dexie `RecordDB` **v3**：`wordRecords` / `chapterRecords` / `reviewRecords`（`revisionDictRecords` 等为死表） |
| 词库 | 静态注册表 `src/resources/dictionary.ts`（约 4192 行，~380 本词书）+ `public/dicts/*.json` 运行时 fetch + SWR 缓存 |
| 音效 | 按键音/提示音 = 本地 wav/mp3 + howler（use-sound 封装）；单词发音 = 有道 `dict.youdao.com/dictvoice`；释义朗读 = `speechSynthesis` |
| UI | Tailwind（darkMode: class、自定义断点 dic3=1100px / dic4=1440px）+ shadcn 部分接入 + headlessui + Radix 原语混用 + **三套 Tooltip 并存** |
| 账户 | **无登录系统**，纯本地应用；mixpanel/GA/Vercel Analytics 埋点三件套 |

### 1.2 关键交互机制（复刻红线，详见第三部分文档第 3 节）

- 输错后 **300ms 吞键窗口** + shake 抖动动画；字母三态变色（含显式空格 `␣` 双色组）
- `window.blur` 自动暂停；任意合法字符键开始（**Enter 不能启动**，Enter 是开始/暂停键）
- 单词错 ≥4 次出现 Skip 按钮（宽度渐入）；新词自动发音 + 下一词发音预取
- Tab 按住临时显示答案/译文（keydown/keyup 配对）；循环模式靠 `:key` remount 重置
- 复习模式 `chapter = -1` 写库；复习进度在 store 与 IndexedDB **双写**；复习算法 = 错误次数排名×0.6 + 最近错误时间排名×0.4
- 听写模式 4 种隐藏类型（全部/元音/辅音/随机），`openBy: user/auto` 决定进入下一章是否自动关闭

## 2. 总体策略

1. **平行新建，不改原仓**：在 `F:\notebook\word\qwerty-learner-vue\` 新建项目；原仓库冻结，作为对照蓝本与资源来源（`public/dicts`、`public/sounds` 直接拷贝）。
2. **数据兼容优先**：localStorage key 与 JSON 结构、IndexedDB 库名/表名/版本 schema **原样保留**，老用户配置与练习记录无缝迁移。
3. **先复刻后优化**：Phase 2~4 逐像素逐交互复刻；Phase 5~6 落地补强项（Toast、二次确认、空状态、自动刷新等，见第三部分）。
4. **死代码不清入**：旧版 `pages/Gallery/`、`Dictionary.tsx`、`CategoryNavigation.tsx`、死 Action（`INCREASE_WRONG_WORD`/`TOGGLE_WORD_VISIBLE`/`SET_REVISION_INDEX`）、`isLoopSingleWord`、`inputCount`、`revision*` 表全部不迁移。
5. **保留已验证的交互习惯**：不改用户已熟悉的快捷键、动画时长、颜色语义（规范第五节"不要随意改变已经成熟的交互习惯"）。

## 3. 技术选型映射表（React → Vue 一一对应）

### 3.1 框架与核心

| 原（React） | 新（Vue） | 迁移说明 |
|---|---|---|

| Vite 4 | Vite 6 | `define` 注入 `REACT_APP_DEPLOY_ENV`/`LATEST_COMMIT_HASH` 平移（建议更名 `VITE_DEPLOY_ENV`，用 `import.meta.env`） |
| TypeScript 4 | TypeScript 5.x | 类型层平移，见第 11 节 |
| react-router-dom v6 | **vue-router 4** | 路由表见第 5 节；GitHub Pages basename 用 `createWebHashHistory` 或 `createWebHistory(import.meta.env.BASE_URL)` |
| Tailwind 3 | Tailwind 3 原配置平移 | `darkMode: ['class']`、`primary=#6366f1`、`dic3/dic4` 断点、自定义 w/h 刻度、`tailwindcss-animate` 全部保留 |

### 3.2 状态与数据

| 原 | 新 | 迁移说明 |
|---|---|---|
| jotai `atomWithStorage` / `atomForConfig` | **Pinia + 自研 persist 工具**（第 6 节） | 必须复刻 `atomForConfig` 的"缺字段合并默认值 + 类型不匹配整体回退"行为；key 一字不差 |

## 6. 状态管理架构（Pinia）

### 6.1 持久化工具 `stores/persist.ts`（数据兼容的关键）

复刻 `atomForConfig` 行为，签名：

```ts
// 读：类型不匹配 → 整体用默认值；默认值有而存储缺的字段 → 合并默认值并回写 localStorage
// 写：直接整体写入 JSON.stringify
export function loadPersisted<T extends Record<string, unknown>>(
  key: string, defaultValue: T,
): T
export function savePersisted(key: string, value: unknown): void
```

- **localStorage key 与原项目一字不差**（共 18 个，见 6.2 表），老用户配置直接生效。
- Pinia 集成方式：store 内 state 初始值用 `loadPersisted()`，提供 `persist()` action 或统一 `subscribe()` 自动回写（推荐 `store.$subscribe` debounce 200ms 批量写，避免高频写 localStorage）。
- `isOpenDarkModeAtom` 例外：存的是裸 boolean（原 `atomWithStorage` 直接 JSON 序列化），`loadPersisted` 需兼容非对象值（`typeof v !== 'object'` 时直接返回 `v as T`）。

### 6.4 `stores/typing.ts` — 打字状态机（19 Action → store actions 映射）

state 结构与原 `TypingState` 完全一致：

```ts
{
  chapterData: { words: WordWithIndex[], index, wordCount, correctCount, wrongCount,
                 userInputLogs: UserInputLog[], wordRecordIds: number[] },
  timerData: { time, accuracy, wpm },
  isTyping, isFinished, isShowSkip, isTransVisible, isSavingRecord
}
```

| React Action | Vue store action | 内部逻辑要点 |
|---|---|---|
| `SETUP_CHAPTER` | `setupChapter(words, {shouldShuffle, initialIndex?})` | 全量重置；shuffle 可选；`initialIndex >= words.length` 归 0；按 words 生成等长 userInputLogs |
| `SET_IS_TYPING` | `start()` / `pause()` | pause 场景：window blur、打开词表抽屉 |
| `TOGGLE_IS_TYPING` | `toggleTyping()` | StartButton |
| `REPORT_CORRECT_WORD` | `reportCorrect()` | `correctCount+=1`；当前词 log.correctCount+=1 |
| `REPORT_WRONG_WORD` | `reportWrong(letterMistake)` | `wrongCount+=1`；log.wrongCount+=1；`mergeLetterMistake` 合并错字映射 |
| `NEXT_WORD` | `nextWord(updateReviewRecord?)` | index+1、wordCount+1、isShowSkip=false；复习模式同步 reviewRecord.index（双写） |
| `LOOP_CURRENT_WORD` | `loopCurrentWord()` | wordCount+1，index 不变 |
| `FINISH_CHAPTER` | `finishChapter()` | isTyping=false、isFinished=true |
| `SKIP_WORD` | `skipWord()` | index+1；越界 → finishChapter 语义 |
| `SKIP_2_WORD_INDEX` | `skipToIndex(newIndex)` | clamp 防御（原 reducer 越界即结束） |
| `REPEAT_CHAPTER` | `repeatChapter(shouldShuffle)` | 复用 words 重置，isTyping=true，保留 isTransVisible |
| `NEXT_CHAPTER` | `nextChapter()` | 重置后等词表加载重新 setupChapter（**优化：由 page 层在词表就绪后调用，避免原项目"words 空数组中间态"**） |
| `TOGGLE_TRANS_VISIBLE` | `toggleTrans()` | Ctrl+Shift+V / 释义按钮 |
| `TICK_TIMER` | `tick(addTime=1)` | time+=addTime；accuracy/wpm 重算（字母级口径） |
| `ADD_WORD_RECORD_ID` | `addWordRecordId(id)` | — |
| `SET_IS_SAVING_RECORD` | `setSaving(v)` | 防章节记录提前落库 |
| `SET_IS_SKIP` | （内部）`showSkip()` | wrongCount>=4 时置 true |

- **计时器**：在 `TypingPage.vue` 里 `watch(store.isTyping)` 启停 `setInterval(1000, () => store.tick())`；ResultScreen 挂载时调 `store.tick(0)` 补算最终数据。
- **保存章节记录**：`watch([isFinished, isSavingRecord])` → `saveChapterRecord(store.state)`（复习模式 chapter=-1）。

## 7. 数据层设计

### 7.1 Dexie（原样 + 响应式升级）

```ts
// 库名 RecordDB，版本 3，schema 原样
wordRecords:    '++id,word,timeStamp,dict,chapter,wrongCount,[dict+chapter]'
chapterRecords: '++id,timeStamp,dict,chapter,time,[dict+chapter]'
reviewRecords:  '++id,dict,createTime,isFinished'
```

- `saveWordRecord` / `saveChapterRecord` / `deleteWordRecord` / `putWordReviewRecord` / `generateNewWordReviewRecord`（0.6/0.4 加权算法）逻辑平移。

- 优化（P1）：错题本/统计/词书进度查询改用 `liveQuery` + VueUse `useObservable`，练习完成返回页面自动刷新（原项目靠手动 reload 翻转）。

### 8.1 `composables/useHowl.ts`（替代 use-sound）

```ts
export function useKeySounds(): [playKeySound, playWrongSound, playCorrectSound]
```

### 8.2 `composables/usePronunciation.ts`（单词发音）

- URL 生成规则平移：`https://dict.youdao.com/dictvoice?audio={word}` + `uk→type=1 / us→type=2 / ja/romaji→le=jap（romaji 先转平假名 kana.ts）/ zh→le=zh / de→le=de / kk·hapin→le=ru / id→le=id`。

### 8.3 `composables/useSpeech.ts`（释义朗读）

### 8.4 自动发音触发点（复刻红线）

## 9. 深色模式

- 策略不变：`<html class="dark">` + Tailwind `dark:` 变体；body `transition-colors duration-300`；亮色底 `#faf9ff` / 暗色 `bg-gray-900`。

  - 读 `isOpenDarkModeAtom`（boolean）；初始值 fallback `matchMedia('(prefers-color-scheme: dark)')`；
  - `watch` 同步 `documentElement.classList`；提供 `toggle()`。
- `index.html` 防闪烁脚本重写（原脚本读已废弃的 `state` key）：

```html
<script>
  (function () {
    try {
      var raw = localStorage.getItem('isOpenDarkModeAtom');
      var dark = raw == null
        ? window.matchMedia('(prefers-color-scheme: dark)').matches
        : JSON.parse(raw) === true;
      if (dark) document.documentElement.classList.add('dark');
    } catch (e) {}
  })();
</script>
```

- echarts 图表暗色：保留 `dispose → init(dom, isDark ? 'purple' : 'light')` 重建逻辑（purple.json 原文件拷贝）。
